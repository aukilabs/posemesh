# Building

Notes for building the Rust workspace in `core/`. Verified in a clean `rust:1.89-slim` container and on Ubuntu with Rust 1.96.

## Prerequisites

- Rust 1.89 or newer (the workspace sets `rust-version = "1.89.0"`)
- A C toolchain — `build-essential` on Debian/Ubuntu
- `git`

```sh
sudo apt install build-essential git
```

That is the whole list. `cmake`, `pkg-config` and `protoc` are not needed: the protobuf code is generated by `pb-rs`, which is pure Rust.

`git` is not optional. `core/networking/build.rs` shells out to `git log -1` and unwraps the result, so if the binary is missing — or you are building from a source tarball with no `.git` directory — the build dies with an error that does not mention git at all:

```
thread 'main' panicked at networking/build.rs:4:83:
called `Result::unwrap()` on an `Err` value: Os { code: 2, kind: NotFound }
error: failed to run custom build command for `posemesh-networking`
```

## Building core

```sh
cd core
cargo build
```

Around 450 crates. Roughly two minutes with a warm cargo cache, about five from cold.

## Submodules

`third-party/` carries OpenCV, protobuf, glm and ios-cmake as submodules. They belong to the SDK build, not to the Rust workspace. You do not need `git submodule update --init` to build `core/` — a fresh clone with empty submodule directories compiles fine.

If you are building the SDK, start from `sdk/` instead.

## Makefile targets

`core/Makefile` defaults `OS` to `macOS` and `ARCH` to `ARM64`, and `build-domain` shells out to `scripts/Build-Library.ps1`, which requires PowerShell. On Linux without `pwsh` you get:

```
$ make build-domain
/usr/bin/env: 'pwsh': No such file or directory
make: *** [Makefile:14: build-domain] Error 127
```

The script itself does support Linux. It has branches for `Linux` (AMD64 to `x86_64-unknown-linux-gnu`, ARM64 to `aarch64-unknown-linux-gnu`, with the cross linker and sysroot set up) and for `Web`. With `pwsh` installed, pass the platform explicitly:

```sh
make build-domain OS=Linux ARCH=AMD64
```

If you only need the Rust library, `cargo build` is enough.

## WASM

```sh
make build-domain-wasm
```

Requires `wasm-pack`.
